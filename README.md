# EASON

## 專案提案：BankPilot 銀行智慧客服 Agent

### 一句話介紹

BankPilot 是一個結合 AI Agents 與自動化流程的銀行客服平台，能從客戶的自然語言需求出發，自動完成身分確認、資料查詢、問題判斷與後續處理，讓客服人員專注在真正需要人判斷的複雜案件。

### 我們想解決的問題

銀行客服每天會收到大量重複問題，例如：

- 「我的信用卡為什麼被扣款？」
- 「可以幫我查最近一筆轉帳嗎？」
- 「我要掛失卡片。」
- 「房貸申請目前到哪裡了？」

傳統客服通常需要在多個系統間切換、複製資料、確認規則，再把結果回覆給客戶。這不只耗時，也容易造成等待過久、資訊不一致或人工操作失誤。

### 解決方案

BankPilot 不是單純的聊天機器人，而是一個可以協作的 Agent Team：

1. **Triage Agent**：理解客戶意圖，判斷問題類型與緊急程度。
2. **Verification Agent**：依照風險等級要求適當的身分驗證，不在對話中暴露敏感資料。
3. **Banking Agent**：透過受控 API 查詢帳戶、交易、卡片或貸款狀態。
4. **Workflow Agent**：自動建立案件、寄送文件、安排回撥，或執行符合規則的服務流程。
5. **Human Handoff Agent**：遇到高風險、模糊或超出權限的情況，整理完整摘要後轉交真人客服。

### 示範情境

客戶說：「我剛剛看到一筆不是我刷的 8,800 元交易，請幫我處理。」

BankPilot 會：

1. 判斷為「疑似信用卡盜刷」高風險事件。
2. 啟動多因素身分驗證。
3. 查詢該筆交易的時間、商店與授權狀態。
4. 暫停卡片後續交易，這個動作需要客戶明確確認。
5. 自動建立爭議款案件並產生案件編號。
6. 將交易摘要、已完成的處理與下一步寄送給客戶。
7. 把完整紀錄交給真人客服，避免客戶重複說明。

### AI Agents 與 Automation 的亮點

- **Agent 選擇工具**：根據意圖與風險，自動選擇查詢、驗證、建案或轉接工具。
- **事件驅動自動化**：收到高風險交易事件後，自動啟動驗證、通知與案件流程。
- **可追蹤的決策紀錄**：每次工具呼叫、資料來源與轉接原因都留下 audit log。
- **風險分級控管**：查詢可以自動化；轉帳、停卡與個資異動等操作必須再次確認或交由人工核准。
- **客服 Copilot**：轉接真人時，自動提供摘要、情緒、已驗證項目與建議回覆。

### 黑客松 MVP

我們會先完成一個可操作的對話 Demo，展示三條流程：

1. 查詢交易紀錄與解釋扣款。
2. 信用卡疑似盜刷的驗證、停卡確認與爭議款建案。
3. 無法處理的案件自動轉接真人客服，並產生完整摘要。

Demo 使用模擬銀行 API 與假資料，避免接觸真實帳戶與個人金融資訊。

### 預期成果

- 將重複性客服問題的處理時間從數分鐘降低到數十秒。
- 讓客服人員收到案件時已具備完整上下文。
- 透過權限、驗證、人工核准與 audit log，讓自動化符合金融服務需要的安全標準。

### 建議技術架構

```text
客戶對話介面
	|
Orchestrator / Triage Agent
	|
  +----+---------+-------------+
  |              |             |
驗證 Agent   Banking Agent  Workflow Agent
  |              |             |
 MFA API     模擬銀行 API   Ticket / Email API
	\        |             /
	 Human Handoff + Audit Log
```

### 30 秒 Pitch

「銀行客服最浪費時間的，不是回答困難問題，而是在不同系統間處理大量重複流程。BankPilot 是一個銀行客服 Agent Team：它能理解客戶需求、依風險完成身分驗證、查詢受控的銀行 API，並自動建立案件與通知。像疑似盜刷這類高風險操作，BankPilot 不會擅自決定，而是要求客戶確認或交給真人核准。這讓銀行客服更快、更一致，也讓自動化真正值得信任。」
